# S8 plan, step S8-13

Part of [the S8 plan](../S8.md), section 5, "Ordered steps".

**S8-13 Addresses move to the domain (M, High).** Kind: agent code; owner applies.
- Infra: the naming module gains the environment's public address. `allowed_origins` and the reCAPTCHA key's domains hold both the public host and the `run.app` host (the bypass of section 4.5). The scheduled job, the uptime check and the synthetic monitor call the public address. The relay's `API_INTERNAL_URL` is the public address: a call from one Cloud Run service to another counts as internal only through a VPC, and DryScope has none. Both services receive `FRONT_DOOR_ADDRESS`, the load balancer's address (S8-13b). The plan check accepts these as named in-place changes. The services' new settings serve only after the next release moves traffic to a revision that has them (section 3); the scheduler, monitors and reCAPTCHA list change at the apply.
- Owner: add the public host to the sign-in authorized domains (per project).
- Tests: mocked plans; no setting names only the `run.app` host afterwards; the plan check refuses a public host of another environment.
- Needs: S8-12 applied and its certificate active.
