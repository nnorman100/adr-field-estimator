# S8 plan, step S8-6

Part of [the S8 plan](../S8.md), section 5, "Ordered steps".

**S8-6 Recovery repoint setting (S, High: Terraform, IAM condition).** Kind: agent code; owner applies only in a drill or an incident.
- Infra: one variable, `sql_instance_override`, empty by default. When set to a recovered instance of the same environment (`dryscope-<env>-pg-` and a suffix), the data root admits that instance in the web app's and the migrator's Cloud SQL access conditions and the app root points both services and the migration job at it. `check-plan.js` accepts this as a named change only when the variable is set, only on those connection settings and conditions, and only for a name of the same environment.
- Docs: `infra/dryscope/README.md`; the incident section of `backups.md`.
- Tests: mocked plans with and without the override; an override naming the other environment, another project or the original instance is refused; with the variable empty the plans are unchanged byte for byte.
- Needs: nothing. Can start now; rebases on S8-8 if that merges first.
