# S8 plan, step S8-6

Part of [the S8 plan](../S8.md), section 5, "Ordered steps".

**S8-6 Recovery repoint setting (S, High: Terraform, IAM condition).** Kind: agent code; owner applies only in a drill or an incident.
- Infra: one variable, `sql_instance_override`, empty by default. For a lost instance only (a zone outage, recovered into another zone of `us-central1`). Damaged data is never repointed: it ends at the validated copy and the row copy-back (section 4.5), so rows written since the chosen minute stay. A regional outage has no repoint either (section 4.5). When set to a recovered instance of the same environment (`dryscope-<env>-pg-` and a suffix), the data root admits that instance in the web app's and the migrator's Cloud SQL access conditions, alongside the original that the services still use, and the app root points both services and the migration job at it. The data root is applied first and the recovered instance's login checked (S8-5, phase 3 and `--recovery`); the app root is applied only after those checks pass. That apply makes a fresh revision with no traffic (section 3), so the owner tags it `candidate`, checks it at the candidate address (health reports database `ok` from the recovered instance), records the serving revision and moves all traffic to it. Putting back runs the other way: the recorded revision tagged `candidate` and checked at the candidate address (health reports database `ok` from the original instance), then all traffic moved to it and the serving address checked, then the app root with the override emptied, then the data root, so the admission is removed only once a checked revision that does not use it serves. `check-plan.js` accepts this as a named change only when the variable is set, only on those connection settings and conditions, and only for a name of the same environment.
- Docs: `infra/dryscope/README.md`; the incident section of `backups.md`.
- Tests: mocked plans with and without the override; an override naming the other environment, another project or the original instance is refused; with the variable empty the plans are unchanged byte for byte.
- Needs: nothing. Can start now; rebases on S8-8 if that merges first.
