# S8 plan, step S8-25

Part of [the S8 plan](../S8.md), section 5, "Ordered steps".

**S8-25 Urgent fix: a new image straight to Cloud Run (M, High: a new workflow, live).** Kind: agent code; the owner approves the workflow.
- CI: a manual-only workflow, `web-urgent-fix.yml`, as the Standard's Core release path asks: "a manual-only workflow deploys a new image straight to Cloud Run with no infrastructure changes; the same release then goes through the normal path." Two inputs (environment, commit on `master`). It builds the image by digest from that commit, deploys it as a new revision of the existing web app service with no traffic, runs the smoke check against the revision (read-only on live, S8-17), moves the traffic, and records the urgent release with its rollback command like any other release. On live it waits for the same environment approval as S8-18. It never runs Terraform, a migration or a rules release, and never changes a service setting other than the image. The same commit then goes through the normal release path (S8-14 and S8-18) before the next ordinary release.
- Docs: the urgent-fix section of the owner's release runbook (S8-20): when to use it, and that the normal release of the same commit follows.
- Tests: the workflow guard tests: manual dispatch only; no step runs Terraform, a migration or a rules release; the image is deployed by digest; live waits for the environment approval; the smoke check on live is the read-only one.
- Needs: S8-14 for test; S8-18 for live; S8-19's manifest reader for the rollback command.
