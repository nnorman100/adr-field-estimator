# S8 plan, step S8-11

Part of [the S8 plan](../S8.md), section 5, "Ordered steps".

**S8-11 Terraform: DNS zones (S, High).** Kind: agent code; owner applies and sets the registrar.
- Infra, data roots: in live, the public zone for `<domain>` with DNSSEC, protected from deletion, and the name-server records that delegate `test.<domain>`; in test, the zone for `test.<domain>`. The Cloud DNS, Certificate Manager and Compute APIs join the API list.
- Owner: point the registrar at the live zone's name servers; after they have spread, add the DS record for DNSSEC.
- Tests: mocked plans; the guard check requires the zone to be protected; a zone for any other name is refused.
- Needs: the domain registered (owner step C), S8-8.
- Order: the live zone for `<domain>` is applied first, then the `test.<domain>` zone. A test plan that creates the `test.<domain>` zone while no `<domain>` zone exists is refused by the plan check (Cloud DNS wants the parent zone created before the child zone).
