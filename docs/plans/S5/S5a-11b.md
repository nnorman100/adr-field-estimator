# S5 plan, step S5a-11b

Part of [the S5 plan](../S5.md), section 5, "Ordered steps".

**S5a-11b Signing links and document links (DB job; moved from S5b-3 on 2026-11-13).** Everything S5b-3 below says, built in S5a so that remote signing is part of customer approval. Delivery: copy, QR and the phone's share sheet, so the technician sends the link by text message or email from their own phone; DryScope sending email itself stays S9 (J7), and DryScope sending text messages itself is not planned (it needs a messaging provider and an owner decision). The link's page shows the same signed page as on-site signing, with the company's authorization and payment terms (S5a-11). The migration also adds the link id to `agreements` (nullable, set when the signer kind is `link`), so the locked record says which link was used. A link is voided by a new estimate as well as by a new submission. Needs: S5a-11, the lane.
