# S5 plan, step S5a-2

Part of [the S5 plan](../S5.md), section 5, "Ordered steps".

**S5a-2 Core job tables (DB job).** DB: `jobs` (client id, created by, field owner, status `draft`/`submitted`/`signed`/`archived`, current draft id, property address, `archived_at`/`archived_by`, revision, last change id, request digest), `job_customers`, `job_claims` (carrier, claim and policy numbers, date of loss, adjuster, deductible), `evidence_objects` (job, object id, kind photo/original/signature, object name, generation, SHA-256, size, type, by; insert-only), and company profile columns on `companies` (address, phone, email, licence, sign-off) with a column-level `UPDATE` grant on those columns only (the owner-only rule is the route's). UI, FE, BE: Drizzle view only. Tests: guard test covers each table; B reads none of A's rows; a row cannot point at another company's job; the runtime cannot update `evidence_objects` or delete anything; applies on a database holding every earlier file. Needs: the lane.
