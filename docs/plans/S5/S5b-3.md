Part of [the S5 plan](../S5.md), section 5, "Ordered steps".

**S5b-3 Signing links and document links (DB job). Moved to S5a-11b on 2026-11-13; the text stays here as that step's detail.** DB: `signing_links`, `document_links` (token SHA-256 only, job, estimate or agreement, set homeowner/adjuster, expiry, used, revoked), attempt counters. UI: Send to the homeowner (create, copy, share, QR, revoke); `/sign` and `/documents` pages. BE: a new access rule `linkRoute` (token in a header, never stored); a link signs once as the technician, who must still hold `sign`; 7 days to sign, 30 days to view after; void on a new submission; one active link per job (a retried create with the same link id voids the unseen token and returns a new one); limits per link and per hashed client address; document links made at signing, revocable by owner or office. Delivery is copy and share only until email exists (J7). Tests: `spec.md` 2.5 checks; two simultaneous homeowner signatures give one agreement (the HTTP race `spec.md` 4.2 lists as open); a link of company A is useless for B's routes. Needs: S5a-11, the lane.
