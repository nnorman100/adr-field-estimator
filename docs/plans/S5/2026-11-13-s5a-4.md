# S5 plan correction: 2026-11-13, S5a-4

Part of [the S5 plan](../S5.md), section 12, "Corrections".

- **2026-11-13, S5a-4.** The company profile routes and the Company settings screen (`web/src/lib/profile/`, `web/src/app/(auth)/sign-in/[address]/company/`, `docs/ACCESS.md` "Company profile API") use no new capability key and no migration, with these choices the plan left open. (a) The read is owner-only too (`profile_manage`, checked before the body), so an estimator's or office user's phone never receives the profile. (b) The revision is the company row's `updated_at` (no new column); a save names it with a client-made `changeId`, and a stale one answers 409 `stale_revision` with the current profile, except that a save asking for what is already stored answers 200. (c) The company name is shown but not editable (the platform operator sets it), and the logo is not stored (J9: text letterhead until then). (d) `companySetupMissing` (`web/src/engine/company-setup.ts`) is the one setup check, shared by the documents and the screen.
