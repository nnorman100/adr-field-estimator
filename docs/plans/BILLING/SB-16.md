# Billing plan, step SB-16

Part of [the billing plan](../BILLING.md), section 5, "Ordered steps".

**SB-16 Billable units, the allowance and the extra (M, High: pricing).** Slice: server.
- BE: pure functions in `web/src/lib/billing/usage.ts`, each for one period (section 4.5): voice minutes from session lengths; credits from ledger rows by the credit table (versioned), in two readings: settled only (what is billed) and committed (settled plus calls in progress at their reservation, what the cap uses); active people in the period; the pooled allowance; the extras; the expected extra charge from the dated prices. `GET /api/billing/usage` (`billing_read`) answers the month so far.
- Tests: worked examples from this plan as fixtures; property tests: more use never lowers an extra, one more active user never raises one, the extras are never negative, the result does not depend on the order of rows; a failed AI call counts nothing in either reading and a call in progress counts in the committed reading only; use before the subscription's start is outside the period; a person last seen before the start is not active in a part month; the pool never falls below last month's; a month computed twice is identical; another company's rows never enter the sum (the isolation matrix row and a planted row).
- Needs: SB-14; SB-5's price copy. B7, B8, B23.
