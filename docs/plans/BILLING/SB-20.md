# Billing plan, step SB-20

Part of [the billing plan](../BILLING.md), section 5, "Ordered steps".

**SB-20 Terraform: the export job (S, High: IAM).** Slice: infrastructure. Owner applies.
- Infra: a Cloud Run job per environment, `dryscope-export-<env>`, with its own account that can read the database as the runtime role does, read the evidence bucket, and write only under the bucket's `exports/` prefix; a rule that deletes objects under that prefix after 7 days; the web app's account may start the job and read `exports/`. A task timeout long enough for a large company (the default is 10 minutes; the limit is 7 days).
- Tests: mocked plans; the plan check's table; the export account can write nowhere else; the lifecycle rule covers only `exports/`.
- Needs: B1.
