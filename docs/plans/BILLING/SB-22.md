# Billing plan, step SB-22

Part of [the billing plan](../BILLING.md), section 5, "Ordered steps".

**SB-22 The export job and its routes (L, High: reads every table of a company).** Slice: server.
- BE: `POST /api/billing/export` (`billing_manage`, allowed in read-only, one running export per company), `GET /api/billing/exports` and a download route that streams the zip to the signed-in owner. The job runs in the company's database context, lists the company's tables from the catalog, writes CSV and JSON per table, the field drafts, the files, and a contents list with counts and checksums. The audit log records the request and each download.
- Docs: `docs/DATA.md` (what an export holds; the excluded tables and why).
- Tests: an export of company A holds every row of A and none of B, with B's rows planted in every table and B's field drafts in the field database (the central test); a new table with a company column fails the test until it is exported or excluded in writing; counts in the contents list equal the database; a download by another company's owner is refused; the object name is never guessable from the company id alone; a second request while one runs is refused.
- Needs: SB-20, SB-21.
