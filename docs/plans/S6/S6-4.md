# S6 plan, step S6-4

Part of [the S6 plan](../S6.md), section 5, "Ordered steps".

**S6-4 Recovery journal and conflict states (M).** UI: the sync chip on every field screen (Saved, Saved on this phone with a count, Can't save with the reason), a "Can't save" detail sheet; for a rejected set of edits: **Save as new draft**, **Discard** (asks), **Try again** (only when the reason can clear); "This job changed on another device"; "This job was finished". FE: `ds-journal` as in section 4 steps 1, 2 and 6, one wrapper for every IndexedDB open (all rows keyed by tenant id and uid) (reopen once on "Connection to Indexed Database server lost", else "Reopen the app", with a version-change handler that closes the connection so an old window never blocks an upgrade, the old app's trap), journal pruning after `acked`, and Save as new draft, offered only for an archived draft (410) or one whose field owner changed (J5), never after the person's own Finish (that path is Back to editing, J4): it copies the **cached draft documents** (not the journal's unsent changes alone) into a new job and draft with new ids, and re-points the queue's `photo` entries with **new photo ids** chosen before the first send (a registered photo id cannot be reused under another job); the same new ids twice make one job. BE: none new (`POST /api/jobs` from S5a-3 creates the job). DB: none. FS: none. Tests: a write queued before a fence and sent after it is refused, stays in the journal, and leaves the submitted record unchanged (the delayed-offline-write race `data-ownership.md` lists); the journal survives reload and a killed page; Save as new draft twice with the same new ids gives one new job with the cached field values and the photos queued for it under new ids; a person's own Finish offers Back to editing, not a new draft; Discard needs the confirm. The archived case (410) is added in S5b-2's pull request, which says so. Needs: S6-3, S5a-3 (for Save as new draft; the rest can start before it), S5a-8 for the fence test. **Starts now** as components and a journal library, shown on `/field` placeholder screens until S5a-6 mounts them; Save as new draft and the fence test when their steps land.
