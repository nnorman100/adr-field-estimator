# Glossary

Words as used in this repo. Entries marked [confirm] are my wording of industry terms; the owner should correct them.

| Term | Meaning |
|---|---|
| Mitigation | Emergency work to stop further damage after a loss (extraction, drying, tear-out). [confirm] |
| Loss | The damaging event; in this app water or mold only |
| Walkthrough | The technician's spoken and photographed inspection (Live or Offline notes) |
| Live | The real-time Gemini voice/video coaching session |
| Offline notes | Record-now, process-later voice notes for bad reception |
| Scope | The confirmed rooms, measured areas, categories, equipment and charges |
| Proposal | Document 1: low–high estimate plus e-signature |
| Itemized claim | Document 2: ADR scope codes with waste factors (not Xactimate codes) |
| Scope defense letter | Document 3: IICRC S500/S520 justification addressed to the adjuster |
| Photo moisture log | Document 4: photos with room, time, location and meter reading |
| Water category 1/2/3 | Clean / gray / contaminated water classes that set demolition rates |
| IICRC | Industry standards body; S500 covers water damage restoration |
| GPP | Grains per pound of moisture in air; used by the drying log |
| LGR dehumidifier | Low-grain refrigerant dehumidifier |
| Drying log | Daily room readings (air, material, thermal) kept as a sidecar |
| Drying watch | Post-signing monitoring of signed jobs (built, flag off) |
| Price book | A company's rates; today ADR's workbook (editor built, flag off) |
| Priced extras | Owner-approved pricing for work the workbook does not cover |
| Revision / proposal hash | Saved version of the scope and its fingerprint; signatures bind to it |
| Signing link | Single-use, 7-day link for a homeowner to sign on their phone |
| Document link | Read-only, revocable, 30-day link to signed documents |
| Sidecar | Mutable private record beside an immutable signed job |
| Company workspace | One company's isolated area |
| Owner / Estimator / Office / Superadmin | Roles; see `docs/ACCESS.md` |
| Support view | Superadmin's audited read-only look at a company |
| Item / slice | One small PR-sized piece of work (the roadmap says "item"; the spec template and commands say "slice") |
| Rollback pair | The previous backend revision and Hosting version kept for a release |
| Pre-1978 rule | Older homes need third-party lead/asbestos testing before demolition; wording is mandatory |
